# Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Several documents open as tabs in Inky's one window, each keeping its place, restored after relaunch, and following renames, moves and deletes, including an agent's.

**Architecture:** Only the active tab is loaded. A tab is a small record (`path`, `view`, `nav`, `scroll`). Switching tabs saves the active document, stores the outgoing tab's place and loads the target through the existing `openDoc`, so the rest of the app keeps reading `app.currentPath` and `app.content` unchanged. The tab helpers are pure functions in `src/lib/tabs.ts`. Rust keeps the open-tab list so it can keep those files reachable, across workspace changes and relaunches. The app-hosted MCP server reports agent path changes as events.

**Tech Stack:** Svelte 5 (runes), SvelteKit, Tailwind 4, shadcn-svelte, Vitest; Tauri 2, Rust, rmcp.

**Spec:** `docs/superpowers/specs/2026-11-18-tabs-design.md`

## Global Constraints

- Build on `main`, macOS first. Use `e.metaKey` and `handleMenu`/`handleKeydown` as they exist on `main` (no `platform.ts`, no `runAction`).
- The tab bar renders only when `app.tabs.length >= 2`, and never in focus mode.
- No duplicates from "open" entry points; in-tab link and Back/Forward navigation may duplicate.
- Background tabs hold no buffer; the unsaved-edits dot applies only to the active tab.
- The localStorage tab list is never trusted for file grants. Grants on restore come only from the Rust-side list in `config.json`.
- localStorage key `inky.tabs` replaces `inky.lastDoc` (migrate once: `lastDoc` becomes a single tab).
- Shortcuts: ⌘W close tab (closes the window when there are no tabs). ⌃Tab / ⌘⇧] next tab, ⌃⇧Tab / ⌘⇧[ previous tab, both wrapping. ⌘1–⌘3 stay views.
- Tab minimum width about 120px, then the row scrolls horizontally. The active tab is kept scrolled into view.
- Run `pnpm check`, `pnpm test` and `make check` before every commit; all must pass.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A save conflict on the active tab.** Switching or closing that tab must do nothing, and the conflict dialog stays up. Background opens still work. (Task 4 helper test; Task 4 manual check.)
2. **A stale or malformed `inky.tabs`** (a file deleted while Inky was closed, or junk JSON). The good tabs restore and bad ones drop silently. (Task 1 parse tests; Task 4 restore logic.)
3. **Renaming a folder that contains several open tabs, including the active one.** Every tab is remapped and the window title follows. (Task 1 `remapTabs` test.)
4. **Closing the last tab.** You get the no-document state, and ⌘W again closes the window. (Task 1 `closeTab` returns `null`; Task 6 handler.)
5. **An agent deletes the active tab's document.** That tab closes and its neighbour loads. (Task 1 `dropTabs` test; Task 3 Rust event test; Task 4 wiring.)

### Task 1: Pure tab helpers

**Files:**
- Create: `src/lib/tabs.ts`
- Test: `tests/tabs.test.ts`

**Interfaces:**
- Consumes: `NavHistory`, `emptyHistory`, `renamePath` (rename as `remapNav`), `forgetPath` from `$lib/navhistory`; `isInside`, `remapPath` from `$lib/paths`; `ViewMode` from `$lib/types`.
- Produces (all mutate `set` in place, like `navhistory.ts`):
  ```ts
  export interface Tab { id: string; path: string; view: ViewMode; nav: NavHistory; scroll: number | null }
  export interface TabSet { tabs: Tab[]; active: string | null }
  export interface StoredTabs { tabs: { path: string; view: ViewMode }[]; active: number }
  export function emptyTabs(): TabSet
  export function activeTab(set: TabSet): Tab | null
  export function findTab(set: TabSet, path: string): Tab | null            // first match
  export function addTab(set: TabSet, path: string, view: ViewMode, opts?: { background?: boolean }): { tab: Tab; existing: boolean }
  export function closeTab(set: TabSet, id: string): string | null           // new active id, null if none left
  export function cycleTab(set: TabSet, step: 1 | -1): string | null         // id to activate, wraps; null if < 2 tabs
  export function moveTab(set: TabSet, id: string, toIndex: number): void
  export function remapTabs(set: TabSet, from: string, to: string): boolean  // path + each tab's nav
  export function dropTabs(set: TabSet, path: string): { activeClosed: boolean } // tabs at/under path; also forgetPath on survivors' nav
  export function serializeTabs(set: TabSet): string                         // JSON of StoredTabs
  export function parseTabs(raw: string | null, lastDoc: string | null): StoredTabs
  ```
  - `addTab`: if `findTab` hits, that tab is returned with `existing: true`, and it becomes active unless `background`. Otherwise a new tab is inserted right after the active tab (or at the end if there is no active tab), with `id` from `crypto.randomUUID()`, `nav: emptyHistory()` and `scroll: null`. It becomes active unless `background`; when there is no active tab it becomes active even if `background`.
  - `closeTab`: closing the active tab activates the right neighbour, else the left one, else `null`. Closing a background tab leaves `active` unchanged.
  - `dropTabs`: if the active tab is dropped, the new active is the nearest surviving tab to its right, else to its left, else `null`.
  - `parseTabs`: junk JSON or a missing key reads as `{ tabs: [], active: 0 }`. Entries without a string `path` are dropped, and an unknown `view` becomes `"split"`. `active` is clamped into range. When `raw` is null and `lastDoc` is set, the result is `{ tabs: [{ path: lastDoc, view: "split" }], active: 0 }`.

**Interfaces:**
- Consumes: everything from Task 1; the commands `set_open_tabs`, `restore_tab` and `clear_workspace(keep: string[])` from Task 2; the event `path-change` from Task 3.
- Produces (used by Tasks 5–6):
  ```ts
  tabSet = $state<TabSet>(emptyTabs());
  tabs = $derived(this.tabSet.tabs);
  activeTabId = $derived(this.tabSet.active);
  async openInTab(path: string, opts?: { background?: boolean }): Promise<boolean>
  async activateTab(id: string): Promise<boolean>   // false when blocked (conflict) or failed
  async closeTab(id: string): Promise<void>
  async closeActiveTab(): Promise<void>            // closes the window when no tab is open
  async cycleTabs(step: 1 | -1): Promise<void>
  moveTab(id: string, toIndex: number): void
  ```
- `openDoc(path, opts)` gains `opts.fromTab?: boolean` (do not record a history visit). It keeps meaning "show in the active tab": on success it sets the active tab's `path`, or creates the first tab when there is none.

Behaviour to implement (the decisions; the bodies are yours):
- **`activateTab(id)`:** if it's already active, return true. Save if dirty; if `conflict` is set, return false. On the outgoing tab, store `scroll = #here()?.scroll ?? null`, `nav = this.nav` and `view = this.viewMode`. Then set `tabSet.active`, `this.nav = incoming.nav` and `this.viewMode = incoming.view` (assign directly, without `setViewMode`, so the default view isn't overwritten). Call `openDoc(incoming.path, { fromTab: true, silent: true, restoreScroll: incoming.scroll ?? undefined })`.
  - If that fails, try `invoke("restore_tab", { path })` and open the returned path.
  - If that fails too, show the toast `Could not open <name>`, drop the tab with `dropTabs`, and activate the new active tab (or call `closeDoc()` if none is left).
  - A `null` scroll means the existing read-position resume applies.
- **`openInTab(path, opts)`:** `addTab(tabSet, path, defaultView, opts)`, where `defaultView` is stored `inky.viewMode` or `"split"`. If the new tab is the active one and is not the loaded document, load it with `activateTab`-style loading. A background add only persists. If the load fails, remove the new tab and return false.
- **`closeTab(id)`:** for the active tab, save first and do nothing on a conflict. Then call `tabs.closeTab`; load the new active tab, or call `closeDoc()` when the result is `null`. A background tab is just removed. **`closeActiveTab()`:** with no active tab, call `getCurrentWindow().close()`.
- **`#persistTabs()`:** called after every change to `tabSet` (add, close, move, remap, drop, active change, view change). It writes `localStorage["inky.tabs"] = serializeTabs(tabSet)` and `invoke("set_open_tabs", { paths })`, ignoring errors. Remove every `inky.lastDoc` write, and `removeItem` it once tabs are persisted. The window title still follows the loaded document, as it does now.
- **`setViewMode`:** also set the active tab's `view`, then persist.
- **Startup (`init`):** replace the `inky.lastDoc` block with `parseTabs(localStorage["inky.tabs"], localStorage["inky.lastDoc"])` → build tab records → activate the stored active tab.
  - If that tab fails to load, it is dropped silently and the next one is tried, until one loads or none are left. Restore is silent: no toasts.
  - Pending open requests and the Welcome doc then go through `openInTab`, after the restored tabs.
- **Factored bookkeeping:** `#pathMoved(from, to)` and `#pathDeleted(path)` take over what `movePath`, `renamePath` and `deletePath` do after their `invoke` succeeds: nav remap/forget, `imagePath`, read positions, highlights, baselines, expanded folders, `currentPath`/title, `refreshTree`, and now `remapTabs` / `dropTabs`. After `dropTabs`, `activeClosed` loads the new active tab, or calls `closeDoc()`.
  - `deletePath` keeps its toast and Undo; Undo does not reopen tabs.
  - `listen<PathChange>("path-change", …)` calls the same two methods. For an agent delete, highlights are forgotten immediately, since there's no Undo.
- **Callers that switch to `openInTab`:** `newDoc`, `pasteAsNewDoc`, `openRecent`, `handleOpenRequest`, `revealHighlight`, and the `saveMineAsCopy` toast action. `#travel` and Preview link-follow keep `openDoc`.
- **Workspace and library:**
  - `closeWorkspace` passes `keep: tabs.map(t => t.path)`.
  - `chooseLibrary` passes `keep: []`, then resets `tabSet = emptyTabs()`, calls `closeDoc()` and persists. Changing the library closes all tabs (my call).
- **Image previews and the zoom viewer** close on tab switch. `openDoc` already does this.
